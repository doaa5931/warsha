# التغيير الثاني: لوحة إدارة باللون الأسود

## الهدف
تحويل لوحة الإدارة إلى واجهة داكنة يغلب عليها الأسود، مع الحفاظ على قابلية القراءة والتمييز بين الأزرار والحالات.

## الملف المعدل

`client/src/pages/Admin.tsx`

## ما تم تغييره

- جعل جذر لوحة الإدارة يستخدم `bg-black text-white`.
- تحويل البطاقات والأقسام إلى درجات داكنة مثل `#111111` و`#151515`.
- تحويل الحدود إلى درجات رمادية داكنة.
- جعل النصوص الثانوية رمادية فاتحة.
- تحويل زر الإجراء الرئيسي إلى لون برتقالي واضح على خلفية سوداء.
- جعل حقول الإدخال والجداول والقوائم المنسدلة مناسبة للخلفية السوداء.
- إضافة الصنف `admin-dashboard` إلى الجذر لاستخدامه في تحسينات CSS لاحقة.

## النتيجة
تظهر لوحة الإدارة الآن بشكل مختلف عن واجهة الموقع العامة: خلفية سوداء، بطاقات داكنة، نص أبيض، ونقاط إبراز برتقالية.

## التحقق
تم تشغيل TypeScript وESLint والاختبارات وبناء الإنتاج بنجاح بعد التعديل.

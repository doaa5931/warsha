# الدخول إلى لوحة الإدارة

## إنشاء المدير الأول

في التشغيل المحلي، لا توجد كلمة مرور مدير ثابتة. أول مستخدم يتم تسجيله في ملف البيانات الجديد يصبح مديرًا تلقائيًا.

1. شغّل المشروع بالأمر `pnpm dev`.
2. افتح الرابط المحلي في Chrome.
3. اضغط **تسجيل الدخول** ثم اختر **إنشاء حساب**.
4. أدخل اسمك وبريدك وكلمة مرور من اختيارك.
5. بعد إنشاء الحساب، سجّل الدخول.
6. ستجد رابط **الإدارة** في شريط التنقل.

## إذا لم يظهر رابط الإدارة

هذا يعني غالبًا أن ملف `.warsha-local/data.json` يحتوي على مستخدمين سابقين، وأول مستخدم فيه ليس حسابك. لإعادة تهيئة النسخة المحلية:

```powershell
# أوقف الخادم أولًا بـ Ctrl + C
Remove-Item -Recurse -Force .warsha-local
pnpm dev
```

بعد ذلك أنشئ الحساب من جديد، وسيصبح مديرًا تلقائيًا.

## سبب عدم وجود كلمة مرور جاهزة

وضع كلمة مرور مشتركة داخل المشروع يجعل أي شخص يحصل على ملف ZIP قادرًا على دخول لوحة الإدارة. لذلك يستخدم المشروع حسابًا محليًا يختاره صاحب التشغيل بنفسه.

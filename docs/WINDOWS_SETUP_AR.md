# تشغيل منصة ورشة على Windows — من دون إعدادات خارجية

هذه النسخة **ذاتية التشغيل**. لا تحتاج إلى Google OAuth أو MySQL أو Docker أو ملف `.env` لتشغيل التسجيل والحجوزات محليًا.

## 1. فك ضغط المشروع

فك ضغط ملف المشروع إلى مسار قصير، مثل:

```text
C:\Projects\warsha-events
```

تجنب فك الضغط داخل مجلد OneDrive إن أمكن، لتفادي تضارب مزامنة الملفات أثناء كتابة ملف البيانات المحلي.

## 2. ثبّت Node.js وVisual Studio Code

ثبّت [Node.js 22 LTS](https://nodejs.org/) و[Visual Studio Code](https://code.visualstudio.com/). افتح PowerShell ثم تحقق:

```powershell
node --version
```

يجب أن يظهر إصدار `v22` أو أحدث.

## 3. افتح المشروع وشغّله

افتح PowerShell داخل المجلد، ثم نفّذ:

```powershell
cd C:\Projects\warsha-events
corepack enable
pnpm install
pnpm dev
```

افتح الرابط الذي سيظهر، مثل:

```text
http://localhost:3000
```

إذا كان المنفذ 3000 مشغولًا، سيختار التطبيق منفذًا آخر مثل 3001 ويعرضه في PowerShell. استخدم الرابط المطبوع فعلًا.

## 4. أنشئ الحساب الأول

من الموقع، اضغط **تسجيل الدخول** ثم اختر **إنشاء حساب**. أدخل الاسم والبريد وكلمة مرور من 8 أحرف أو أكثر.

> أول حساب تنشئه بعد تشغيل نسخة جديدة يصبح مديرًا تلقائيًا. ستجد بعدها رابط **الإدارة** في الشريط العلوي لإدارة الفعاليات والحجوزات.

## 5. أين تحفظ البيانات؟

ينشئ التطبيق مجلدًا تلقائيًا هنا:

```text
.warsha-local\data.json
```

يحوي الحسابات والحجوزات والتقييمات والإشعارات. لا تشاركه إذا أدخلت بيانات شخصية حقيقية.

## 6. إعادة ضبط كل شيء

أوقف الخادم عبر `Ctrl + C`، ثم من جذر المشروع نفّذ:

```powershell
Remove-Item -Recurse -Force .warsha-local
pnpm dev
```

سيُعاد إنشاء برنامج الفعاليات، ويصبح أول حساب جديد مديرًا مجددًا.

## 7. فحوص التطوير

```powershell
pnpm check
pnpm lint
pnpm test
pnpm build
```

## 8. حلول الأخطاء الشائعة

| المشكلة | الحل |
|---|---|
| `pnpm is not recognized` | نفّذ `corepack enable` ثم أغلق PowerShell وافتحه من جديد. |
| `'cross-env' is not recognized` | نفّذ `pnpm install`، ثم `pnpm add -D cross-env` عند الحاجة، وبعدها `pnpm dev`. |
| المنفذ 3000 مستخدم | استخدم المنفذ البديل الذي يطبعه الخادم؛ لا تحتاج لتغيير أي ملف. |
| لا يظهر رابط الإدارة | أنشئ حسابًا أولًا، أو احذف `.warsha-local` ثم أنشئ أول حساب من جديد. |
| تريد إزالة الحسابات والبيانات | أوقف الخادم ثم احذف `.warsha-local` كما في الخطوة السادسة. |

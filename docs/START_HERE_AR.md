# ابدأ هنا

شغّل المشروع على Windows بهذه الأوامر فقط:

```powershell
cd C:\Projects\warsha-events
corepack enable
pnpm install
pnpm dev
```

افتح رابط `localhost` الذي يظهر في الطرفية، ثم أنشئ أول حساب من صفحة **تسجيل الدخول → إنشاء حساب**. لا تحتاج إلى `.env` أو Google OAuth أو قاعدة بيانات خارجية.

للتفاصيل وحلول الأخطاء، راجع [دليل Windows](WINDOWS_SETUP_AR.md).

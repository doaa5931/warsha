# ورشة — منصة فعاليات وحجوزات عربية ذاتية التشغيل

> تطبيق React وTypeScript لإدارة الفعاليات والحجوزات. الواجهة عربية بالكامل، ويعمل المشروع محليًا دون Google OAuth أو MySQL أو ملف `.env` أو مفاتيح API. ينشئ التطبيق ملف بيانات محليًا تلقائيًا عند أول تشغيل.

## التشغيل السريع على Windows

بعد فك ضغط المشروع، افتح مجلد `warsha-events` في Visual Studio Code، ثم افتح PowerShell داخل المجلد ونفّذ:

```powershell
corepack enable
pnpm install
pnpm dev
```

افتح الرابط الذي يظهر في PowerShell، مثل `http://localhost:3000` أو `http://localhost:3001` إذا كان المنفذ الأول مستخدمًا.

## الدخول كمدير

1. افتح الموقع واختر **إنشاء حساب**.
2. اكتب اسمك وبريدك الإلكتروني وكلمة المرور التي تختارها.
3. أول حساب يتم إنشاؤه في نسخة بيانات جديدة يصبح مديرًا تلقائيًا.
4. سجّل الدخول بالحساب نفسه.
5. ستظهر لك صفحة **الإدارة** في شريط التنقل، ومنها تستطيع إضافة الفعاليات وتعديلها وإدارة الحجوزات.

لا توجد كلمة مرور مدير جاهزة داخل المشروع. هذا مقصود حتى لا يستطيع أي شخص يملك نسخة الملفات استعمال حساب إداري مشترك.

إذا كانت النسخة قد شُغّلت سابقًا وأُنشئ مستخدم عادي، أوقف الخادم ثم احذف مجلد `.warsha-local` وأعد تشغيل `pnpm dev` لإنشاء نسخة بيانات جديدة. على Windows:

```powershell
Remove-Item -Recurse -Force .warsha-local
```

## الفئات والورش

يبدأ المشروع بـ 20 ورشة منشورة، خمس ورش في كل فئة:

- تقنية.
- حِرف.
- تصوير.
- تصميم.

تظهر الورش عند اختيار الفئة من الصفحة الرئيسية، ويمكن البحث فيها وترتيبها وحجز المقاعد المتاحة.

## ما الذي يعمل؟

| القسم | السلوك المحلي |
|---|---|
| الحسابات | إنشاء حساب بالبريد وكلمة مرور، تسجيل دخول وخروج، وجلسة محلية موقعة. |
| الفعاليات | 20 ورشة أولية قابلة للبحث والتصفية والحجز. |
| الملف الشخصي | حجوزات حالية وسابقة، بحث وفرز، ورسائل تأكيد وتذكير داخلية. |
| التقييمات | إضافة تقييم بعد إكمال الحجز فقط. |
| الإدارة | أول حساب يملك لوحة لإضافة الفعاليات ونشرها وأرشفتها وتحديث الحجوزات. |
| البيانات | تحفظ تلقائيًا في `.warsha-local/data.json` ضمن مجلد المشروع. |
| اللغة | العربية فقط، مع اتجاه RTL ثابت. |

## أوامر الجودة

```powershell
pnpm check
pnpm lint
pnpm test
pnpm build
```

| الأمر | وظيفته |
|---|---|
| `pnpm check` | فحص أنواع TypeScript. |
| `pnpm lint` | تحليل ESLint للواجهة. |
| `pnpm test` | اختبارات الحساب المحلي والحجوزات وقواعد التقييم. |
| `pnpm build` | إنشاء نسخة الإنتاج داخل `dist`. |

## البنية المختصرة

```text
client/src/pages/       # Home وAuth وProfile وAdmin
client/src/components/  # نموذج الحجز والبطاقات والتنقل والتقييمات
server/programCatalog.ts # كتالوج الورش العشرين والفئات الأربع
server/db.ts            # تخزين JSON محلي وحسابات وجلسات وبيانات المنصة
server/routers.ts       # tRPC للحسابات والحجوزات والإدارة
.warsha-local/          # ينشأ تلقائيًا؛ لا يُرفع إلى Git
```
